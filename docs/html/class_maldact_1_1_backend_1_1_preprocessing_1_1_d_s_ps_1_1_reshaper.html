enum Maldact.Backend.Preprocessing.DSPs.Reshaper.ReshapeMethod

The strategy used to align mismatched dimensions.

Enumerator
Interpolation 

Stretches or squashes the vector using linear interpolation.

Strict 

Throws an exception if dimensions do not perfectly match.

TruncateOrZeroFill 

Copies data up to the target length, padding with zeroes if target is larger.
