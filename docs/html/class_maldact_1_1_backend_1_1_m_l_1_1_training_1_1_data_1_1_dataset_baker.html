Discovers the manifest inside the source directory, bakes all streams in parallel using bounded runtime worker pools, and performs short-circuit fault management.

Parameters
sourceDirectoryThe directory path containing the raw dataset manifest and its associated binary streams.
targetDirectoryThe destination directory where the processed tensors and stamped manifest will be written.
contractThe preprocessing contract containing the transformations to apply to the streams.
maxDegreeOfParallelismThe maximum number of concurrent data streams to process simultaneously.

ArgumentExceptionThrown when input paths are invalid or empty.

InvalidOperationExceptionThrown when structural configuration preconditions are unfulfilled.
InvalidDataExceptionThrown when structural validation steps detect corrupt or unaligned inputs.
