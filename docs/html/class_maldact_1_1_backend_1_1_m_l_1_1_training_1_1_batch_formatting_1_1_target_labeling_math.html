Provides mathematical utilities for converting raw timestamped ground truth events into flat 1D floating-point arrays suitable for Machine Learning tensor ingestion.

Calculates a flat multi-hot encoded sequence array representing the presence of classes at specific granular timesteps within each window. Suitable for RNN, LSTM, or Transformer sequence classifiers.

Parameters
rawBatchThe list of formatted time windows containing ground truth events.
classesThe ordered array of class names mapping to tensor indices.
windowDurationMsThe duration of each window in milliseconds.
seqLenThe number of granular timesteps to divide the window into.
Returns
A flat 1D array of shape [batch_size * seq_len * num_classes].
